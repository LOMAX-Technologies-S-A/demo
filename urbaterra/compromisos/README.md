## Variant: Visual Board

### Design stance
Dashboard visual con métricas. Más pulido, pensado para presentación a cliente. Summary cards arriba con KPIs, sidebar oscura con perfil de usuario.

### Key choices
- **Layout:** Sidebar + main wrap con border radius (efecto "contenido flotante"). Summary bar con 4 KPIS arriba del kanban
- **Cards:** Más visuales — dots de prioridad circulares, progress bar gruesa con colores, avatares apilados
- **Colores:** Acento naranja (`#f79720`) para botón principal "Semana actual". Categorías con badge uppercase
- **Interacción:** Modal para crear compromiso más completo con row de campo doble. Cards con color coding fuerte
- **Detalles:** Breadcrumb arriba del título, bloqueados con borde rojo lateral, completados con opacidad reducida

### Trade-offs
- **Fuerte:** Más profesional, ideal para presentar al cliente, métricas visibles de entrada, diseño más trabajado
- **Débil:** Más pesado visualmente, el summary agrega scroll vertical en pantallas pequeñas

### Best for
Presentación a Urbaterra como propuesta de UI. Dar una primera impresión más pulida del sistema.
